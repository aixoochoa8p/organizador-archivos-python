# Organizador Automático de Archivos

Script en Python que organiza automáticamente los archivos de una carpeta 
según su extensión. Ideal para ordenar carpetas desordenadas sin intervención manual.

---

##  Funcionalidades

- Clasificación automática por extensión
- Crea carpetas por tipo de archivo (PDF, imágenes, Excel, etc.)
- Organización rápida sin intervención manual
- Compatible con cualquier carpeta local

---

##  Tecnologías utilizadas

- Python 3
- os
- shutil

---

##  Cómo usarlo

1. Clonar el repositorio
git clone https://github.com/aixochoa/organizador-archivos-python

2. Ejecutar el script
python organizador_archivos.py

3. Ingresar la ruta de la carpeta a organizar
organizar_archivos("C:/ruta/de/tu/carpeta")

---

##  Estructura generada automáticamente

tu-carpeta/
├── PDFs/
├── Imágenes/
├── Excel/
├── Videos/
└── Otros/
